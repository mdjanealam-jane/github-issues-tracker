 1.What is the difference between var, let, and const?
 Ans: If we first talk then each of them are used to declare variables with some difference. var is the oldest way to declare variable before ES6 came. let used to declare variable where we have to change the values later like when running a loop. And in const we can't change the value of a variable, if we try to change then it'll show an error.

 2.What is the spread operator (...)?
 Ans: The spread operator is one of the latest feature came with ES6 in 2015 which we used to copy an array's element to a new destination.

3.What is the difference between map(), filter(), and forEach()?
Ans: Both of them are used to run a loop on an array but purpose is different. forEach() is a standard replacement of for loop but it returns undefined. in map() it creates a new array by applying a function to every element of the original array. It doesn't affects the original array. and finally the filter() used to create a new array which contains only the new elements that passes a specific condition.
